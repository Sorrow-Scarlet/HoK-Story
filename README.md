## 用法

### 对文案

1. 于 `Github 网页端` Fork 本仓库
2. 克隆 自己的 Fork 到本地
3. 创建自己的文案分支
4. 在合适的分类下写自己的文案
5. 发起 Pr 等待合并

### 对 Dafan

1. 运行下列命令

```
git clone https://github.com/Sorrow-Scarlet/HoK-Story.git
```

2. 肝事件
3. 定期在`文案目录`执行下列命令：

```
git pull
```

## 事件划分

以长度划分，分为以下类型：

- 主线
- 支线
- 唯一小事件
- 重复小事件
